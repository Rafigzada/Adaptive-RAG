✅ 1. Create Conda Environment from a .yaml File

Assuming you have a file like environment.yaml in your project folder:
🔧 Command:
        conda env create -f environment.yaml
        This will:
            Create a new environment (with the name defined inside the .yaml file)
            Install all dependencies listed

🧠 Note:
        If the environment name is rag_env, it will create that.
        You can rename it while creating like this:
            conda env create -f environment.yaml -n my_custom_env


✅ 2. Activate the Environment

Once created:
        conda activate rag_env

If you renamed it, use:
        conda activate my_custom_env


✅ 3. Clone the Git Project (e.g., from GitLab)

From your terminal or JupyterLab terminal:
        git clone https://gitlab.com/your-username/your-project-name.git
        cd your-project-name

Then, assuming environment.yaml is inside that project folder:
        conda env create -f environment.yaml
        conda activate rag_env

✅ Optional: Update an Existing Env from YAML

If you've already created the env and want to update it:
        conda env update -f environment.yaml --prune

--prune removes packages not listed in the YAML.
